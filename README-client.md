# Laboratory Activity 4 - Websocket API

The structure of this repository is the following:

- [client](/client) contains the Film Manager client application, implemented in REACT;
- [databaseV2.db](databaseV2.db) is the updated SQL database file, this should be used within the Film Manager Service (either your implementation or uploaded solution);
- [ws_message_schema.json](ws_message_schema.json) is the designed schema representing the format of Websocket messages.
